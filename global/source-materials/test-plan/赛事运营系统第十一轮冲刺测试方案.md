## 冰球橄榄球正式流程覆盖

### 预期目标

以冰球、橄榄球比赛（本轮数据源新增标准化识别处理的运动项目）为样本，从草稿制定开始，完整走通系统全部正常操作链路：草稿制定 → 草稿比对 → 生成正式版 → 赛程文件提交 → 开售 → 比赛状态流转 → 赛果审核确认 → 开奖 → 赛果导出；并覆盖两条变更处理支线：草稿阶段的赛程变更处理、开售后的异常变更管理，以及开售后的比赛监控视角。验证标准化后的冰球/橄榄球比赛在端到端流程中各环节衔接正确、状态码流转通畅、赛果信息正确回写。
