# 一、测试类型

功能测试

# 二、测试目的

验证竞猜赛事运营系统在保存草稿、生成正式版时，能够正确校验草稿内比赛的主数据源是否已删除或已置换并给出提示（不阻断保存）；添加比赛弹窗能够正确过滤主数据源已删除或已置换的比赛。覆盖足球、篮球、冰球、橄榄球 4 个运动项目。
