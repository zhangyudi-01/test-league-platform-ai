# 竞猜赛事运营系统 · 表-模块-接口追溯矩阵（第 13 轮冲刺同步版）

> 依据：PRD《已实现操作日志》接口清单（含第 13 轮冲刺新增）+ **实库 `toto_permission.urls`**（149 条已入库权限 + `#147` 设计文档权限，2026-10-26 连库核验）+ **api-docs/league-core-api 八份 OpenAPI 规范** + **第 13 轮数据库设计与 SQL Dump（`202610261418.sql` 187 张表）**。
> 阅读方式：
> - **按模块查**：每行 = 一个功能点，给出其权限点（实库 level1/level2/level3 及 permission_id）、触发接口（实库 urls + OpenAPI 规范 + PRD 操作日志三方互证）、读写的主表；
> - **按表反查**：附录 A"表 → 模块/接口"反向索引，可定位任意表被哪些功能读写；
> - 图例：**R**=读 / **W**=写（含增删改）；接口前缀省略说明见附录 B。
> 调用链说明：前端 → **data-bff**（`/data-backend/*` 为代理透传至 data-backend；草稿/开奖 real-time、report、upload、download、otp 为 BFF 自营）→ data-backend → 库表。
