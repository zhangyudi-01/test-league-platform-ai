# 赛事数据管理系统数据库设计

# 说明：

*   数据库版本使用mysql8，小版本待定
    
*   时区东8区。
    
*   数据库部署在k8s集群内。
    
*   dev\_newgoal为研发库，test\_newgoal为测试库。
    
*   数据库字符集utf8mb4，排序规则utf8mb4\_bin（大小写敏感）。
    
*   小数都用decimal，根据位数需求设置长度。
    
*   人工录入编辑的表都有create\_time，update\_time，create\_account,update\_account
    
*   所有create\_time初始化为datetime 默认值DEFAULT CURRENT\_TIMESTAMP 非空
    
*   所有update\_time初始化为datetime 默认值DEFAULT CURRENT\_TIMESTAMP ON UPDATE CURRENT\_TIMESTAMP 非空

赛程说明：

*   一个奖期(bd\_game\_draw)下可以在不同批次(bd\_batch)内添加同一场比赛(来自s\_match),保存到草稿（bd\_batch\_matchup\_draft）最终生成正式赛程bd\_batch\_matchup，要求游戏(sale\_game\_list)不同
    
*   不同奖期可以可以添加相同比赛
    
*   赛果批次(bd\_batch\_matchup\_draw)从同奖期赛程bd\_batch\_matchup中取比赛，对于不同批次下同一场比赛,可以在一个赛果批次中添加多条记录
    
*   批次bd\_batch的开售状态
    
*   批次bd\_batch的提交状态点提交到sftp按钮
