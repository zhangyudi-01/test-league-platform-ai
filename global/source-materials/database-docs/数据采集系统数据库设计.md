# 数据采集系统数据库设计

# 说明：

*   数据库版本使用mysql8，小版本待定
    
*   dev\_newgoal为研发库，test\_newgoal为测试库。
    
*   数据库字符集utf8mb4，排序规则utf8mb4\_bin（大小写敏感）。
    
*   小数都用decimal，根据位数需求设置长度。
    
*   人工录入编辑的表都有create\_time，update\_time，create\_account,update\_account
    
*   所有create\_time初始化为datetime 默认值DEFAULT CURRENT\_TIMESTAMP 非空
    
*   所有update\_time初始化为datetime 默认值DEFAULT CURRENT\_TIMESTAMP ON UPDATE CURRENT\_TIMESTAMP 非空

### 同行getcompetitionschedule接口分析

按照Mode的不同，返回如同行接口文档

| **字段** | **内容描述** |
| --- | --- |
| Mode | 赛制形式,<br>Round 轮次<br>Period 分阶段<br>Group 分组<br>None 无 |
| Period | 赛事分阶段json 数据，当mode 为Period时才会出现<br>键值名为阶段名称<br>每个赛事阶段有Mode, Schedule 两个数据<br>Mode 为赛制形式,分Round,Group,None 三种，参考以上说明<br>Schedule 为赛事列表数组 |
| Schedule | 赛事列表数组<br>Id    编号数组，共4位，第1位比赛编号，第2位联赛编号，第3位主队编号,第4位客队编号<br>Date 比赛时间<br>N     是否为中立场<br>以下数据当比赛完场才会出现<br>Score      比分数组，共2位，第1位主队比分，第2位客队比分<br>RedCard  红牌数组，共2位，第1位主队红牌，第2位客队红牌<br>Half      半场比分<br>Note     备注信息<br>ScoreAll   全场比分数组（含加时赛比分），格式同Score<br>ScorePoint  点球比分数组，格式同Score |
| Competition | Competition 联赛 Json数组<br>key  赛事编号 （键值名）<br>Name    赛事名称<br>ShortName   赛事简称<br>Color     赛事背景色 |
| Team | Team 球队json数据<br>key  球队编号 （键值名）<br>Name    球队名称<br>ShortName   球队简称 |
