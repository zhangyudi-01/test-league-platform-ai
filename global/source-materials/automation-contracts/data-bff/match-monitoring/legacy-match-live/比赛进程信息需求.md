*   **业务规则**
    

1.  用户点击列表中的比赛状态时，查询系统中是否存在该比赛的进程信息，是则在比赛下方显示其进程信息，否则不显示；
    
2.  点击标签页，可切换数据源，默认为贝泰数据；
    
3.  贝泰数据进程信息，按数据源的 order\_id 顺序排列，包括：
    
    1.  事件，区分主客队，中立事件在主客队均显示，进球、换人、红黄牌等事件用图标显示，对应事件如下；
        
        | **数据源事件类型** | **事件名称** |
        | --- | --- |
        | match\_started | 比赛开始 |
        | break\_start | 中场休息 |
        | injury\_time\_shown | 补时时间公布 |
        | match\_ended | 比赛结束 |
        | red\_card | 红牌 |
        | yellow\_card | 黄牌 |
        | yellow\_red\_card | 黄红牌 |
        | substitution | 换人 |
        | score\_change | 进球 |
        
    2.  相关球员，事件涉及的球员名称，换人事件区分上场及下场球员，无相关球员时显示空；
        
    3.  比赛时间，显示事件发生时比赛的进行时间，格式为：{match\_time}+{stoppage\_time}；
        
        1.  match\_time 为 0 或空 时，显示空；
            
        2.  stoppage\_time 为 0 或空时，只显示 match\_time，示例：10'；
            
        3.  均不为 0 或空时，都显示，示例：45'+1'。
            
    4.  官方补时，事件类型为‘injury\_time\_shown’时，显示‘injury\_time\_announced’值，其他事件显示空；
        
    5.  比分，显示事件相关的比分，无数据时显示空；
        
    6.  主客队顺序与监控列表一致；比分顺序与主客队一致。
        
4.  纳米数据进程信息，按数据源的默认顺序排列，包括：（仅实现足球）
    
    1.  事件，区分主客队，中立事件在主客队均显示，进球、换人、红黄牌等事件用图标显示；
        
    2.  相关球员，事件涉及的球员名称，换人事件区分上场及下场球员，无相关球员时显示空；
        
    3.  比赛时间，显示事件发生时比赛的进行时间；
        
        1.  上半场超过 45 分钟后，即纳米数据事件类型为 11 的事件及其之前发生的所有事件中，比赛时间大于 45 分钟时，显示为“45'+{n}'”；
            
        2.  下半场超过 90 分钟后，即纳米数据事件类型为 12 的事件及其之前发生的所有事件中，比赛时间大于 90 分钟时，显示为“90'+{n}'”；
            
        3.  加时赛超过 120 分钟后，即纳米数据事件类型为 26 的事件及其之前发生的所有事件中，比赛时间大于 120 分钟时，显示为“120'+{n}'”；
            
        4.  其他情况显示实际时间，示例，上半场补时阶段的第 46 分钟，显示为 45'+1'，下半场刚开场的第 46 分钟，显示为 46'。
            
    4.  比分，显示事件相关的比分，无数据时显示空。
        
    5.  主客队顺序与监控列表一致；比分顺序与主客队一致。
