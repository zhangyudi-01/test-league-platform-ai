### 比赛赛程监控

#### （1）比赛列表

*   **原型**
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AAQaJz9Oke/img/f1cb2503-3b85-455c-9c45-5df0bd9eb68c.png)
    
*   **业务规则**
    

1.  查询条件包括：
    
    1.  奖期，通过下拉框选择，包含系统中所有的奖期编号及其开售的游戏，按奖期 ID 倒序排列，默认选中当前用户之前选择的奖期，未选择时默认选中 ID 最大的奖期；
        
    2.  自动刷新，通过下拉框选择，包含：关、5s、10s、30s、1m、5m，默认为关；
        
    3.  运动项目，支持多选，默认选择全部；
        
    4.  编号范围，仅可输入数字，最多可输入4位，默认为空，范围支持输入相同编号；
        
    5.  开赛时间，可选择开始时间和结束时间，显示到分，默认为空，选择日期后默认时间为 00:00:00-23:59:59；
        
    6.  游戏，包含：全部、足球单场、胜负过关、下半场比分，从赛程的开售游戏中查找，默认选择全部。
        
2.  查询结果为对应奖期下所有已开售批次的正式版比赛列表，按~~置顶状态~~、比赛编号正序排列，不分页，具体信息包括：
    
    1.  编号，即比赛编号中的流水号，隐藏前几位 0，如“25051-0001-A123456”显示为“1”；
        
    2.  运动项目；
        
    3.  赛事级别，即比赛所属赛季对应的赛事级别，级别为空时不显示；
        
    4.  赛事简称，赛程信息中比赛所属赛季对应的北单简称，为超链接样式（具体规则同赛程草稿）；
        
    5.  轮次，赛程信息中的轮次；
        
    6.  开赛时间，标准化比赛信息中的开赛时间；
        
    7.  主队全称、客队全称，标准化比赛信息中的球队，名称显示比赛所属赛季关联的球队北单全称，为空时显示球队全称，为超链接样式（具体规则同赛程草稿）；~~主客队顺序与北单赛程一致；~~
        
        1.  赛果未审核时，主客队顺序与标准化比赛信息一致；
            
        2.  赛果已审核时，主客队顺序与当前用户审核结果的顺序一致；
            
        3.  赛果已确认时，主客队顺序与确认结果的顺序一致；
            
    8.  主队排名、客队排名，标准比赛信息中的排名，无则不显示；排名顺序与主客队一致；
        
    9.  比赛状态、开奖状态，根据标准化比赛信息中的比赛状态进行显示，映射关系详见“通用需求”；足球项目，比赛状态为“比赛中”，获取贝泰直播数据（live）中的 match\_clock、stoppage\_clock 和 match\_status 值；
        
        1.  获取不到直播数据时，比赛状态显示“比赛中”；
            
        2.  match\_clock 为空时，比赛状态显示 match\_status 值，match\_status 为空时，显示“比赛中”；
            
        3.  match\_clock 非空，stoppage\_clock 为空时，若 match\_status 为live、1st\_half、2nd\_half、overtime、1st\_extra、2nd\_extra，则比赛状态显示 match\_clock 值，只显示分钟，示例：10'，否则显示 match\_status 值，match\_status 为空时，显示“比赛中”；
            
        4.  match\_clock 和 stoppage\_clock 均非空时，则显示 {match\_clock}+{stoppage\_clock}，只显示分钟，示例：45'+1'。
            
    10.  半场、全场比分，优先显示已确认的比分，其次为**当前用户**已审核的比分，之后是系统采集的开奖用的比分，无比分时显示“-”；比分顺序与主客队一致；
        
    11.  赛果状态，未确认时，显示**当前用户**的审核状态，已确认时，所有用户均显示为已确认；
        
    12.  ~~图，已上传赛果截图时，按钮高亮，否则置灰；~~
        
    13.  告警，显示对应比赛未确认状态的告警条数（含比赛异常和数据异常），为超链接样式，条数为 0 时置灰；
        
    14.  变更，显示对应比赛待执行~~和执行中~~状态的变更条数，为超链接样式，条数为 0 时置灰；（不含系统自动处理的任务）
        
    15.  预警，显示对应比赛的预警条数，为超链接样式，条数为 0 时置灰；
        
    16.  事件，显示对应比赛的类型为比赛异常、预警，异常渠道为贝泰、纳米、~~同行~~，且时间节点为开售后的事件条数，为超链接样式，条数为 0 时置灰；
        
    17.  备注，显示对应比赛的备注条数，为超链接样式；
        
    18.  ~~监控记录，显示~~~~**当前用户**~~~~填写的该比赛监控记录的最后更新时间，无记录时显示“-”；~~
        
    19.  置顶，显示**当前用户**的置顶状态；
        
3.  ~~当比赛的告警列数值大于 0 时，将该行的背景填充为对应的告警记录中最高告警级别的颜色，如，编号为 1 的比赛，存在 2 条~~~~未核实及已核实状态的告警记录，其中最高告警~~
    
4.  当比赛存在以下情况时，将比赛的背景填充为对应颜色：（存在系统事件未被标注的问题，方案待定）
    
    1.  存在时间节点为“开售后”、异常类型为“比赛提前”的事件时，填充为红色；
        
    2.  存在时间节点为“开售后”、异常类型为“比赛推迟”的事件时，填充为黄色；
        
    3.  存在时间节点为“开售后”、异常类型为“比赛延期”、“比赛取消”、“比赛中断”、“比赛腰斩”的事件时，填充为橙色；
        
    4.  上述事件均不包含状态为“已解除”的事件；
        
    5.  上述事件区分人工添加事件和数据源事件，存在人工添加事件时，按事件更新时间最大的人工添加事件进行填充，否则，按事件更新时间最大的数据源事件进行填充；
        
    6.  无上述事件，但列表中主客队~~顺序~~与赛程不一致时，填充为绿色，一致后取消该填充。
        
5.  比赛列表根据设置的自动刷新时长自动更新，只更新列表内的数据，保留之前的查询、筛选结果，及滚动条位置；
    
6.  点击【赛果表区间段】，弹出赛果表计算框，详见后续章节；
    
7.  勾选比赛，点击【填写监控记录】，弹出填写记录框，详见后续章节；
    
8.  勾选比赛，点击【赛果审核】，弹出赛果审核框，详见后续章节；
    
9.  勾选比赛，点击【赛果确认】，弹出赛果确认框，详见后续章节；
    
10.  勾选比赛，点击【批量确认】，跳转赛果确认页，详见后续章节；
    
11.  勾选比赛，点击【赛果回退】，弹出赛果回退框，详见后续章节；
    
12.  ~~点击【上传赛果截图】，弹出图片上传框，详见后续章节；~~
    
13.  点击列表标题的对应项可进行比赛筛选，具体包括：
    
    1.  “赛事简称”，弹出赛事筛选框，具体规则同**比赛信息管理**；
        
    2.  “比赛状态”，包含：未开赛、比赛中、完场、推迟、中断、腰斩、取消，默认全选，支持反选；
        
    3.  “赛果状态”，包含：未审核、已审核、已确认，默认全选；
        
    4.  “告警”，包含：无告警、有告警，默认全选；
        
    5.  “变更”，包含：无变更、有变更，默认全选；
        
    6.  “预警”，包含：无预警、有预警，默认全选；
        
    7.  “事件”，包含：无事件、有事件，默认全选；
        
    8.  “备注”，包含：无备注、有备注，默认全选；
        
    9.  “开奖状态”，包含：未开奖、已开奖，默认全选。
        
14.  点击列表中的赛事简称、主队全称、客队全称的外链，在新标签页打开对应网站~~，同时记录 1 条当前用户对该比赛的监控记录，记录内容为“无变动”~~；
    
15.  点击列表中的比赛状态，弹出对应比赛的进程信息，详见后续章节；
    
16.  ~~点击列表中的“图”，左侧显示对应比赛的截图，详见后续章节；~~
    
17.  点击列表中的告警，在新标签页打开“告警管理”页，显示对应比赛未确认状态的告警记录；
    
18.  点击列表中的变更，在新标签页打开“变更管理”页，显示对应比赛待执行~~和执行中~~状态的变更记录；
    
19.  点击列表中的预警，在新标签页打开“预警管理”页，显示对应比赛的预警记录；
    
20.  点击列表中的事件，在新标签页打开“事件管理”页，显示对应比赛的事件记录；
    
21.  点击列表中的备注，弹出备注框，详见后续章节；
