match_id

异常详情
用户
校验：
 a. 异常原因，通过级联下拉框选择，默认为请选择，具体内容及排序见toto_dict表，dict_key = 'attribution_title'，dict_value = 1 （没有点的是一级标题），dict_value = 1.1 （这种是一级标题对应的二级标题，他可能有多个），校验异常原因必须是在toto_dict表存在的组合和内容
 b. 异常渠道，通过下拉框选择，包括：联赛官网、当地媒体、俱乐部官网、官方社交媒体；
 c. 异常详情，支持汉字、字母、数字和字符，长度小于等于 300 个字符数。
**入库：**
保存当前用户对应比赛的监控记录；
添加对应的事件，并生成预警记录。
