# 输出 Excel 格式规格（excel-format-spec）

本文件定义 `convert_md_to_excel.py` 输出工作簿的精确格式。修改输出样式前必读；`tests/sample-testcases.xlsx` 是本规格的基准产物。

## 1. 工作簿结构

| 顺序 | Sheet 名 | 来源 | 类型 |
|---|---|---|---|
| 1 | `首页` | 自动生成 | 索引页 |
| 2..n | 各 `##` 小节标题 | 输入 md 的每个表格 | 标准用例表或辅助表 |

- sheet 名清洗：`\/ * ? : [ ]` → `-`；截断到 31 字符；与已有 sheet 重名时追加 `-2`、`-3`。
- 无表格的 `##` 小节不生成 sheet。
- 一个 `##` 小节有多个表时，后面的表沿用同一 sheet 规则追加为独立 sheet（重名自动去重）。

## 2. 首页 sheet

| 单元格 | 内容 |
|---|---|
| A1（合并 A1:F1） | `测试用例`，18pt 加粗 |
| A2（合并 A2:F2） | `——<工作簿标题>`，14pt 加粗 |
| A4 / B4 | `Sheet` / `用例数/行数` |
| A5.. | 各 sheet 名称、行数 |
| 列宽 | A–F 均 28 |
| 对齐 | 全部顶端对齐 + 自动换行 |

## 3. 标准测试用例 sheet

识别条件：表头包含 `测试项`、`测试点`、`执行步骤`、`预期结果` 四列。

| 行 | 内容 |
|---|---|
| 第 1 行 | `时间：xxxx-xx-xx  姓名：xxx`，合并 A1:H1（列数 <8 时合并到末列） |
| 第 2 行 | `执行开始时间`，合并 A2:G2（列数 <7 时合并到末列） |
| 第 3 行 | 表头，D9EAF7 蓝底、加粗、水平垂直居中、行高 30 |
| 第 4 行起 | 数据行 |

样式：

- 冻结窗格 `A4`；自动筛选 `A3:<末列><末行>`。
- 全表细边框（D9D9D9）；数据单元格顶端对齐 + 自动换行。
- 第 1、2 行行高 24。

列宽（按表头名匹配，未匹配列用 24）：

| 列 | 宽 |
|---|---|
| 序号 | 10 |
| 冲刺 | 12 |
| 测试项 | 18 |
| 测试点 | 32 |
| 数据变量 | 28 |
| 前置条件 | 42 |
| 执行步骤 | 42 |
| 备注 | 28 |
| 预期结果 | 42 |
| 测试结果1/2/3 | 10 |

## 4. 辅助 sheet（追溯索引、执行计划、元数据等）

- 第 1 行表头（同样蓝底加粗样式），第 2 行起数据。
- 冻结 `A2`，自动筛选 `A1:<末列><末行>`，边框与换行同上。
- 列宽按表头名匹配标准用例列宽表，其余 24。

## 5. 单元格文本清洗规格

所有单元格：

1. `&nbsp;` → 空格。
2. `<br>`/`<br/>`/`<br />`（大小写不敏感）→ `\n`。
3. 其余 HTML 标签（`</?[a-zA-Z][^>]*>`）→ 删除。
4. Markdown 反引号 → 删除。
5. 连续 3+ 换行压缩为 2（一个空行）。
6. 去首尾空白；全角空格 `　` → 半角。

仅 `前置条件`、`执行步骤`、`预期结果` 三列追加内联编号拆行：

- 拆分点正则：编号（1–2 位数字 + `.`）位于行首，或前一个字符是 `。；;：:，,）)>　` 或空白等自然边界，且 `.` 后不紧跟数字。
- 命中 ≥2 个拆分点才拆；否则原样保留。
- 拆分后每条一行；编号前的引导语（如 `数据状态：…`）独立成行保留在前。
- 已含 `\n` 的单元格（`<br>` 拆出）不再做内联拆分。

## 6. 数据保真要求

- 单元格文字逐字保留，只做第 5 节列出的清洗；不改写、不概括、不翻译。
- md 表数据行数与输出 sheet 数据行数必须一致（转换后读回校验）。
- 空单元格输出空字符串。
