> 状态：`ready`，已确认范围的测试方案待审核；接口文档同步和实际执行仍待验证

接口业务及契约测试。以竞彩赛程为列表主体，核验请求过滤、聚合字段、队序、比分、直播对象、计数和只读行为；响应预期依据当前需求、接口契约及用户确认，数据库用于独立核对数据来源。

### 统一约定

- 除参数测试另有说明外，均在已授权的受控测试环境使用 GET，请求的 `sportIds` 和闭区间业务日覆盖目标赛程；成功预期为 HTTP 200、`code=0`。业务错误只断言已有依据的 `code`，不猜测未定义的错误文案和 HTTP 状态。
- 足球、篮球的竞彩官方 ID 可重号。各场景通过运动项目、官方比赛 ID 和隔离业务日定位目标；默认日期场景可能有共享数据，不能假设整个响应只包含测试创建的赛程。
- 数据库相关测试点的备注引用 DC-001 或 ADC-001；具体造数、独立 SQL 和清理方案在自动化设计阶段确定。`null`、空字符串及字段缺失不视为同一种结果。
- 本表只列已能确定主要预期的测试点。尚不能定判的场景及其原因见第五节，不能用旧实现替代确认。

## 二、测试范围

**纳入**：运动项目与业务日期、列表记录与排序、竞彩源字段、标准比赛补充、主客队及排名、可确定的比分场景、贝泰直播对象、事件/备注计数、查询只读性和已定义的业务错误。

**不纳入**：页面自动刷新计时、列头筛选控件、滚动位置、颜色实际渲染、超链接样式和弹窗交互。比赛进程、事件详情及备注读取/保存由各自 operation 的接口方案负责。认证失败、无法绑定的参数格式和性能指标没有本接口可用的确定契约，不在本表猜测返回值。
